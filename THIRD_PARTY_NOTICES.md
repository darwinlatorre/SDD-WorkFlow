# Upstream notices

First-party framework code/documents and SVGs use the
[framework MIT license](licenses/sdd-workflow-MIT.txt), also retained at the
checkout's root LICENSE. Installation never replaces a project's own LICENSE.

Skills are fetched directly from their official repositories. Their original terms,
not the framework MIT, apply: [Auth0](https://github.com/auth0/agent-skills),
[Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design),
[CodeGraphContext](https://github.com/CodeGraphContext/CodeGraphContext),
[Microsoft Playwright CLI](https://github.com/microsoft/playwright-cli), and
[Vercel agent-skills](https://github.com/vercel-labs/agent-skills).
The [source table](docs/skills.md) records selected refs/subtrees/native names.

Source subtrees remain unchanged; available repository LICENSE/NOTICE files are
downloaded into each new skill's `upstream-notices/` directory where applicable.
Existing skill directories are preserved without a new audit or update. There is
no vendored source/terms inventory. External links are provenance, not a claim of
exhaustive integration or licensing verification. Reading upstream setup/design
instructions is not authority to execute them; role and human gates still apply.
